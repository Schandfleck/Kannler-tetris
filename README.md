# Kannler-tetris

## Install

### 1. Clone the Repo
___

### 2. Install node

Ubuntu/Fedora

```
sudo apt update && sudo apt install node -y
```

Arch

```
sudo pacman -S node
```

### 3. Run the Server

run `node server.js`

___

### 4. Playing

go to http://localhost:3000 if you want to play or http://localhost:3000/referee if you are the referee
